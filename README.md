# **Twitter Sentiment Analysis**

## **Overview**

This project performs **sentiment analysis on Twitter data**, classifying tweets as **positive** or **negative** using Natural Language Processing and Machine Learning techniques.

## **Dataset**

* **Sentiment140 Twitter Dataset**
* ~1.6 million tweets
* Labels converted to binary:

  * `0` → Negative
  * `1` → Positive

---

## **Tech Stack**

* Python
* Pandas, NumPy
* NLTK
* Scikit-learn

---

## **Approach**

* Loaded and cleaned raw Twitter data
* Preprocessed text using:

  * Stopword removal
  * Stemming (Porter Stemmer)
  * Lowercasing and regex cleaning
* Converted text to numerical features using **TF-IDF**
* Trained a **Logistic Regression** model
* Evaluated performance using **accuracy score**

---

## **Outcome**

* Built an end-to-end NLP pipeline
* Successfully classified tweet sentiment at scale
